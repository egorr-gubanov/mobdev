# Лабораторная работа: Мобильное приложение "Простой калькулятор"

## Как это устроено (Структура файлов)

Проект разбит на несколько логических частей, чтобы код был чистым и понятным:

1.  **`MainActivity.kt`** - отвечает за связь кнопок на экране с программной логикой.
2.  **`CalculatorViewModel.kt`** - здесь находится вся математическая логика.
3.  **`activity_main.xml`** (в папках `layout` и `layout-land`) — файлы дизайна.
4.  **`themes.xml`** - здесь я вынес общие стили для кнопок, чтобы дизайн был единообразным и код не дублировался.

## Основные функции и примеры кода

### 1. Работа с числами (Double)
Все расчеты ведутся в формате `Double`, что позволяет работать с десятичными дробями.
```kotlin
val num1 = previousInput.toDouble()
val num2 = currentInput.toDouble()
val result = when (currentOperation) {
    "+" -> num1 + num2
    "*" -> num1 * num2
}
```

### 2. Умное обновление экрана
Когда вы нажимаете на знак операции (например, `+`), первое число улетает в строку истории сверху, а основное табло очищается для ввода следующего числа.

### 3. История операций
Последний результат всегда отображается мелким шрифтом над основным числом.
