# Лабораторная работа: Мобильное приложение "Список контактов"

## Обзор проекта
Приложение для Android, отображающее список контактов из телефонной книги в минималистичном стиле iOS. Проект выполнен на Kotlin с использованием XML Views и соблюдением всех современных требований к разработке.

## Как это устроено (Структура файлов)

Проект разбит на логические части для обеспечения чистоты кода и удобства поддержки:

*   **`MainActivity.kt`** — основной контроллер приложения. Управляет разрешениями (Runtime Permissions), инициализирует список и обрабатывает клики.
*   **`ContactAdapter`** — адаптер для `RecyclerView`, который связывает данные контактов с визуальными элементами. Реализована логика динамических аватарок с инициалами.
*   **`activity_main.xml`** — главный экран приложения. Использует `fitsSystemWindows="true"` для корректного отображения под системными барами.
*   **`item_contact.xml`** — дизайн одного элемента списка в стиле Apple: круглая аватарка, шрифт `sans-serif-medium` и тонкий разделитель.
*   **`dialog_contact_details.xml`** — верстка всплывающего окна `BottomSheetDialog` для отображения детальной информации.
*   **`strings.xml`** — все текстовые ресурсы вынесены в отдельный файл (никакого хардкода в коде).

## Основные функции и примеры кода

### 1. Фоновая загрузка данных
Чтение контактов — тяжелая операция, поэтому она выполняется в фоновом потоке, чтобы не блокировать UI.

```kotlin
thread {
    val contacts = fetchAllContacts() // Работа с ContentResolver
    runOnUiThread {
        recyclerView.adapter = ContactAdapter(contacts) { showContactDetails(it) }
    }
}
```

### 2. Работа с разрешениями
Реализована логика `ActivityCompat.requestPermissions`. Если доступ запрещен, пользователь видит информативный экран с кнопкой запроса. Если доступ разрешен — список загружается автоматически.

### 3. Современный UI (iOS Style)
*   **Minimalist Design:** Белый фон, тонкие серые разделители (`#C6C6C8`), шрифты без засечек.
*   **Интерактивность:** Использование `BottomSheetDialog` для деталей и `selectableItemBackground` для отклика на нажатия.

## Соответствие техническому заданию (ТЗ)

*   **RecyclerView:** Используется вместо устаревших ScrollView для эффективной работы с памятью.
*   **Пакет:** `me.contactapp` (соответствует требованиям, нет `com.example`).
*   **Ресурсы:** Полное отсутствие строк в коде, всё через `getString(R.string...)`.
*   **Стабильность:** Обработаны пустые значения (Null-safety) и исключена возможность падения при отсутствии контактов.
*   **Интерфейс:** Реализована защита от "наползания" на системные бары через `android:fitsSystemWindows`.

## Как запустить
1. Соберите проект в Android Studio.
2. Запустите на эмуляторе или реальном устройстве.
3. Нажмите "Grant Permission" и разрешите доступ к контактам.
4. Если список пуст, добавьте контакт с именем и номером телефона в стандартное приложение "Контакты".
